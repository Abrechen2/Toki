# Contributing to Toki

Thanks for helping. Bug reports, ideas and pull requests are welcome.

## Before you open a pull request

- Keep rules in `Packages/TokiCore` and cover them with tests (`swift test`).
- New user-facing text: German first, with the English translation in the same
  change (`Toki/Localizable.xcstrings`).
- Never put real personal time data into tests or fixtures; use made-up values.
